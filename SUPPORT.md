# Support

Automatist is **free and open source**. Support is community, best-effort — there is no
paid support, no priority tier, and no guaranteed response time.

## Bugs & feature requests

Please use **GitHub Issues**: https://github.com/atj393/automatist-android/issues

- Search existing issues first to avoid duplicates.
- Use the bug-report or feature-request template.
- Include your app version, device model, and Android version for bugs.
- Do **not** paste API keys, tokens, or other people's personal data into public issues.

## Private matters

- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) — do not use public issues.
- **Other private inquiries:** email **support@automatist.cloud**.

## Using the app

- Provider setup, on-device models, and workflows are documented in the
  [README](README.md) and [docs/local-model-import.md](docs/local-model-import.md).
- Cloud AI requires your own provider API key; the fully on-device option needs no key or
  network after the model is downloaded.

There is no payment or donation link inside the Android app.
